# Arpent — site publié

Branche servie par GitHub Pages (la branche `main` n'est pas modifiée).

- `arpent/` : le site (version statique, un seul fichier + photos).
- `arpent/dvf/` : ventes immobilières réelles utilisées par l'estimation, générées par le workflow
  « Données DVF » à partir des *Demandes de valeurs foncières géolocalisées* (DGFiP / Etalab, Licence Ouverte 2.0).
- `tools/build_dvf.py` : le script de génération.
